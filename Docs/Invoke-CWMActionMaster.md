# Invoke-CWMActionMaster

## SYNOPSIS
Invokes a bodyless POST action.

## DESCRIPTION
Builds a ConnectWise Manage URL and sends a POST request without a request body. Supports `ShouldProcess`.

## PARAMETERS

### -Endpoint
The API endpoint for the action.
